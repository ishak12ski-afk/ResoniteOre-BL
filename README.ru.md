# ResoniteOre

**Язык:** [English](README.md) | Русский | [Português](README.pt.md) | [Français](README.fr.md)

ResoniteOre — мод для Terraria Mobile на базе [Bunny Loader](https://github.com/JonataOliveiraa/Bunny-Loader). Добавляет новую подземную руду, набор инструментов, меч и дополнительные возможности передвижения.

**Текущая версия:** 1.5.2  
**Платформа:** Terraria Mobile, Bunny Loader API v2  
**Статус:** В разработке. Некоторые возможности ещё не проверены в самой игре.

## Возможности

- **Резонитовая руда:** по задумке генерируется под землёй после победы над Пожирателем миров или Мозгом Ктулху, в том числе в существующих мирах.
- **Резонитовые слитки:** выплавляются из руды и используются для создания снаряжения.
- **Резонитовая кирка:** мощность кирки 75%.
- **Резонитовый топор:** мощность топора 110%.
- **Резонитовый молот:** мощность молота 80%.
- **Резонитовый меч:** каждый второй взмах выпускает резонансную волну.
- **Ускорение:** скорость передвижения увеличивается на 20%.
- **Рывок:** два быстрых нажатия влево или вправо запускают рывок в соответствующую сторону, как у щита Ктулху. В текущем коде окно двойного нажатия составляет около 0,42 секунды, перезарядка — 0,58 секунды.

В моде есть внутриигровая локализация на русском и английском языках.

## Установка

1. Установите версию Bunny Loader, совместимую с вашей Terraria Mobile.
2. Возьмите готовый архив мода `.bl`, если он у вас уже есть. Чтобы упаковать исходники из репозитория самостоятельно, поместите `manifest.json` и папку `content/` в корень ZIP-архива, затем замените расширение `.zip` на `.bl`.
3. Откройте Bunny Loader, импортируйте пакет `.bl` и включите мод.
4. Запустите Terraria и войдите в мир.

**Примечание:** сейчас в репозитории находятся исходники, а готового файла `.bl` в нём пока нет. Сохранения модов TL Pro не конвертируются автоматически в Bunny Loader. Перед тестированием рекомендуется сделать резервную копию миров.

## Структура исходников

```text
manifest.json
content/
  main.js
  Common/
    Players/
    Systems/
  Content/
    Items/
    Projectiles/
    Tiles/
  Localization/
    en-US.json
    ru-RU.json
```

## Состояние разработки

ResoniteOre начинался как мод для TL Pro, а затем был перенесён на Bunny Loader API v2. Текущие исходники содержат игровые классы на JavaScript и локализации, но успешная установка мода ещё не означает, что все механики корректно работают в Terraria.

Если обнаружите ошибки, особенно с появлением руды или рывком, [создайте Issue](https://github.com/ishak12ski-afk/ResoniteOre-BL/issues) и укажите версии Terraria и Bunny Loader.
